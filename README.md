# Курсовая на тему Сервисы "Инвесткопилка" 

## Описание проекта
Проект позволяет пользователям накапливать средства путем автоматического округления сумм покупок,
совершаемых с использованием банковской карты. Разница между реальной стоимостью покупки и округленной суммой
направляется на специальный накопительный счет («Инвесткопилка»).

## Основные возможности:
Настройка удобного порога округления (например, 10, 50 или 100 рублей)
Автоматическое зачисление разницы между фактическим платежом и округленным значением на счет инвесткопилки
Простота накопления средств благодаря активной оплате картами

## Пример использования
Предположим, вы установили порог округления равным 50₽. Если ваша покупка составила 1712₽, 
система автоматически округлит её до ближайшего большего значения, равного 1750₽ и переведёт разницу (38₽) на счёт вашей инвесткопилки.
